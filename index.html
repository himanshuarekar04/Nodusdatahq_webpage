Everything you need to know about Shopee product data

Answers to common questions regarding REST API keys, direct data feeds, payload structures, accuracy guarantees, and market coverage.

How do I get API keys for real-time Shopee PDP product data?

You can request API access directly through our inquiry form or contact team. We provision production and sandbox API credentials instantly with full REST API documentation and code samples.

Can I receive direct automated data feeds without writing code?

Yes! We deliver automated, scheduled raw datasets (in JSON, CSV, or Parquet format) directly to your AWS S3 bucket, Google Cloud Storage, or automated webhook endpoints for zero-code integration.

What data fields are included in the Full PDP get_pc Raw JSON payload?

Our payloads include 100% complete, untruncated Shopee response attributes: item_id, shop_id, models variation arrays, tier_variations with option images, product_price single values & discounts, product_shipping SLA, seller metadata, and active vouchers.

Which international Shopee markets are covered?

We cover all 12 active major Shopee markets: Brazil (BR), Mexico (MX), Argentina (AR), Singapore (SG), Malaysia (MY), Thailand (TH), Philippines (PH), Vietnam (VN), Indonesia (ID), Cambodia (KH), Laos (LA), and Taiwan (TW).

Does the $5 / 1k requests pricing cover all countries in a single multi-market API?

No. We provide dedicated APIs for a single Shopee market based on your specific requirements. Choose your region — we will provide a dedicated API for that market. Each API is engineered for your selected country or region, and the fixed pricing of $5 per 1,000 requests applies per individual market API.

What is the data accuracy guarantee and uptime SLA?

We guarantee 99.8%+ field-level data accuracy through continuous validation pipelines, backed by a 99.9% uptime SLA for high-throughput enterprise requirements.

Why choose NodusData over general web scraping APIs like Bright Data or Oxylabs?

General scraping APIs charge high monthly retainers ($300–$500+/mo), bill for failed attempts, and return generic HTML without full variation arrays. NodusData is 100% specialized in Shopee PDP data, offering a fixed rate of $5 per 1k successful requests ($0 charge for failed attempts) with complete get_pc raw JSON payloads.

How does NodusData handle Shopee's anti-bot protections & IP blocks?

NodusData operates a fully managed infrastructure with automated residential proxy rotation, CAPTCHA solving, and dynamic JS rendering. You receive instant, clean HTTP 200 OK JSON responses via simple REST API endpoints without managing proxy rotators or code fixes.
